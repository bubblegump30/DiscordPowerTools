# Discord PowerTools

Created by **KyleAustin85** · Version **1.6.0**

Bring your local Discord tools into one Purple Dragon dashboard: themes, workspaces, favorite channels, local notes, saved messages, media inspection, focus timers, link cleaning and performance diagnostics.

### Highlights

- 17 dashboard sections with keyboard tab navigation.
- Workspace profiles and per-server shortcuts.
- Save selected message text and inspect visible attachments locally.
- Focus/break timer, theme presets and optional FPS display.
- Performance controls that preserve native Discord command menus.
- Local data snapshots you can copy or download.

### Setup

Install through a userscript manager, reload Discord in your browser, and click the Purple Dragon launcher. Drag the launcher to move it. Escape closes the dashboard.

### Privacy and scope

PowerTools does not extract your Discord token, send automated messages, grant Nitro or modify billing. Cosmetic previews are local. Saved records stay in your browser/userscript manager and are shared across Discord accounts in that browser profile. Storage may fall back to Discord-origin local storage if manager storage is unavailable or fails. Exports contain private saved records; keep them private. Cosmetic images are omitted and there is no automatic snapshot import.

Advanced request guards are optional and off by default; their effect depends on userscript-manager sandboxing. Link cleaning applies to PowerTools copy/open tools. Local notification controls do not change account settings. Performance improvements vary by device and Discord version.

For the Discord website only, including PTB and Canary. Discord UI changes may affect selectors. Version 1.6.0 has automated simulated-DOM coverage; live Discord and cross-manager acceptance are still pending.
